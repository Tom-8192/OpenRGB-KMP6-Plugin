First release of the **OpenRGB 1.1 plugin** for the **Aukey KM-P6** RGB mouse pad (USB `04D9:A1FA`, Holtek) on
**Linux**, where OpenRGB's own "Holtek Mousemat" driver cannot see the pad (its lighting interface has no endpoint,
so Linux creates no hidraw node for it).

### Download

| File | Contents |
|---|---|
| `OpenRGB-KMP6-1.0.0-linux-x64-qt6.tar.gz` | `libOpenRGB-KMP6.so` (built on Ubuntu 24.04, Qt 6.4), udev rule `60-openrgb-kmp6.rules` |

### Installation

Copy `libOpenRGB-KMP6.so` to `~/.var/app/org.openrgb.OpenRGB/config/OpenRGB/plugins/` (Flatpak) or
`~/.config/OpenRGB/plugins/` and restart OpenRGB. OpenRGB's udev rule already grants access; otherwise install the
included rule (see README).

### Features

- Modes Static, Wave, Breathing, Neon (the order of the pad's button) and Off; brightness 0–9, speed 0–4, wave
  direction - the levels of the vendor software G-aim.
- Sent through usbfs control transfers; the keyboard interface keeps its driver.
- A setting is sent once it stayed unchanged for half a second; no direct mode (the pad stores every setting).
- Starting OpenRGB sends nothing; the last setting sent is remembered, OpenRGB profiles store and load it.
- Unplugging and replugging is detected; runs alongside the KM-P6 RGB Tool (shared lock).
- Status page under *Settings → KMP6*, log messages with the prefix `[KMP6]`.

### Tested

Bazzite (kernel 7.2) with the OpenRGB 1.1 Flatpak on the real pad: detection, all modes, brightness and speed.
